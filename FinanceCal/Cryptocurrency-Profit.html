Cryptocurrency Profit Calculator Documentation

The Cryptocurrency Profit Calculator helps investors calculate potential profits or losses from their cryptocurrency investments.

Features:

  • Select cryptocurrency and fiat currency.
  • Enter investment amount and purchase price per unit.
  • Displays real-time price of the selected cryptocurrency using the CoinGecko API.
  • Calculates profit/loss and displays it in both absolute and percentage terms.
  • Shows results in a graphical form using Chart.js.

Formulas Used:

Current Value: (Investment Amount / Purchase Price) * Current Price

Profit/Loss: Current Value - Investment Amount

Profit/Loss Percentage: (Profit/Loss / Investment Amount) * 100

API Integration:

We use the CoinGecko API to fetch real-time cryptocurrency prices in various fiat currencies.

Chart.js Integration:

We integrate Chart.js to visualize the profit and investment comparison in a doughnut chart.
